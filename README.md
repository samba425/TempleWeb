# 🏛️ UTTHARANDHRA SABARIMALA Ayyappa Swami Temple

A modern, responsive temple website showcasing our sacred heritage and community services.

## About This Website

This website serves as the digital home for devotees and visitors, providing:
- 🙏 Temple information and spiritual significance
- 📅 Daily pooja schedules and special events
- 🎨 Beautiful photo gallery of temple premises
- 💝 Online donation facility for devotees
- 📞 Contact information and directions
- 👥 Admin dashboard for temple management

## Technology

Built with modern web technologies:
- **Frontend**: Angular 17 (Standalone Components)
- **Styling**: Angular Material & Custom SCSS
- **Backend**: Firebase (Database, Storage, Authentication)
- **Payments**: Razorpay Integration

## Website Features

### For Devotees
- **Home**: Welcome message and temple highlights
- **About**: Lord Ayyappa's significance and temple history
- **Services**: Daily poojas, special rituals, and ceremonies
- **Gallery**: Image gallery of temple events and festivals
- **Donations**: Secure online donation with automated receipts
- **Contact**: Location, timings, and contact details

### For Administrators
- **Dashboard**: Overview of donations and statistics
- **Content Management**: Update temple information
- **Gallery Management**: Add/remove temple photos
- **Donation History**: Track all contributions

## Development

### Prerequisites
- Node.js 18+
- Angular CLI: `npm install -g @angular/cli`

### Local Development
```bash
npm install
npm start
```
Visit http://localhost:4200

### Build for Production
```bash
npm run build
```
