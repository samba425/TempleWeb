# Asset Directory for Temple Website

## Images to Add

Place your temple images in this directory:

### Required Images

1. **ayyappa.jpg** (500×600)
   - Main image of Lord Ayyappa for About page
   - Recommended size: 500×600 pixels
   - Format: JPEG, optimized to < 200 KB

2. **temple-exterior.jpg** (1920×1080)
   - Temple building exterior for hero background
   - Recommended size: 1920×1080 pixels
   - Format: JPEG, optimized to < 300 KB

3. **temple-interior.jpg** (1920×1080)
   - Temple sanctum interior
   - Format: JPEG, optimized to < 300 KB

### Gallery Images

Add multiple images for the gallery:
- Format: JPEG or PNG
- Recommended size: 1200×800 pixels
- Optimized to < 200 KB each
- Upload via Admin Dashboard

### Optimization Tools

Use these free tools to optimize images:
- https://tinypng.com/
- https://squoosh.app/
- https://imageoptim.com/

### Image Naming Convention

Use descriptive names:
- `pooja-ceremony.jpg`
- `temple-festival-2024.jpg`
- `lord-ayyappa-sanctum.jpg`
- `devotees-darshan.jpg`

### Placeholder Images

If you don't have images yet, the website uses placeholder images from:
- https://via.placeholder.com/
- https://images.unsplash.com/

Replace these with actual temple photos before going live!

---

**Note:** Do NOT commit actual images to git if the repository is public. Add them through the admin dashboard after deployment.
